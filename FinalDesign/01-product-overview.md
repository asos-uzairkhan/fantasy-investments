# 01 — Product Overview

## Vision

Fantasy Investments is an ongoing, multi-year investment competition that teaches teenagers how markets work before they can legally invest. Each participant builds a portfolio of real stocks, funds, crypto, and commodities and is scored purely on **percentage gain/loss**, tracked against the S&P 500. The production version turns the invite-only prototype into a self-service website that any teenager can join (subject to an account limit) and manage their own portfolio through the UI, month to month, indefinitely.

## Target Audience

- **Primary:** Teenagers (13–17) learning about investing.
- **Secondary:** Parents/guardians and competition organisers (admins).

## What the Prototype Proved

- Teenagers engage with a leaderboard-driven competition using real market data.
- The monthly buy/hold/sell cycle with equal weighting is simple enough to understand yet realistic.
- Firebase Realtime Database + static hosting (GitHub Pages) is a viable, near-zero-cost platform.
- Daily price refresh from Yahoo Finance via a Python script works in practice.

## Prototype → Production Deltas

| Area | Prototype | Production |
|------|-----------|------------|
| Joining | Admin hand-creates CSV + Firebase entries | **Self-service sign-up page** (username, email, password) — no admin approval needed, gated only by a configurable account limit |
| Duration | Fixed 2026 calendar year | **Ongoing, multi-year** — data is stored per year/month so the competition simply continues year after year |
| Scoring | Absolute £50 starting capital | **Percentage gain/loss only** — no stored reference amount. Users may enter any hypothetical amount in the UI to see what it would be worth, but this is never saved |
| Authentication | Custom SHA-256 hashes in RTDB, username-only | **Firebase Authentication** (email + password), with a migration/claim path for existing users |
| Portfolio creation | Fixed CSVs generated by Python script | **In-app portfolio editor** — participants pick their own symbols for next month at sign-up and any time afterwards |
| Monthly changes | Rule existed, no UI — impossible in practice | Participants can freely edit **next month's** portfolio themselves at any time (no admin involvement) |
| Password reset | Admin-only reset | Skeleton "forgot password" screen (no email sending yet) — user contacts admin, who resets it manually |
| Admin panel | Password management only | User management (soft/hard delete), symbol catalogue (add/soft-delete via repo + script), account-limit configuration |
| Data refresh | Client-triggered on first login of the day | Manually run Python script that updates CSV/JSON files in the repo (default: last 60 days; overridable for full-history backfill) |
| Price/symbol data storage | CSV files in the repo (used only as a fallback) | Still CSV/JSON files in the repo — now the **sole source of truth**; Firebase is not used for price or symbol data at all |
| Frontend | Plain HTML/CSS/JavaScript | **React** (via Vite), keeping Chart.js via `react-chartjs-2` |
| Hosting | GitHub Pages | GitHub Pages (unchanged) |
| Account deletion | N/A | Self-service **soft delete**; only an admin can **hard delete** (permanent) |
| Rules/education | Static rules card | Rules + lightweight educational content ("Why diversify?", glossary) |
| Security rules | Effectively world-writable | Locked-down per-user rules tied to Firebase Auth; leaderboard/portfolios visible only when logged in |

## Core Features (Production)

1. **Sign-up & onboarding** — create an account with username, email (optional), password; immediately set up next month's portfolio (see [03](03-authentication-and-accounts.md)).
2. **Leaderboard** — rankings by cumulative % return, profit/loss chart, return-over-time chart, S&P 500 benchmark (carried over from prototype, adapted to percentages).
3. **My Portfolio** — current holdings, next month's editable portfolio, per-symbol charts, and a **monthly performance history** bar chart + table spanning every year the account has been active.
4. **Explore Symbols** — browse the symbol universe by category with price charts.
5. **Rules & Learn** — competition rules, glossary, short explainers.
6. **Admin panel** — manage users, manage the symbol catalogue (add / soft-delete), configure the account limit, run/monitor the manual data refresh.
7. **Sponsors** — sponsor cards (carried over).

## Explicit Non-Goals

- No real money, payments, or brokerage integration.
- No free-form intraday trading — the monthly equal-weight cycle stays.
- No social features (chat, comments) in v1 — avoids moderation burden for a minors-focused site.
- No native mobile apps — responsive web only.
- No paid Firebase features (Cloud Functions/Blaze) — everything runs on the free Spark plan; scheduled work is done by an admin manually running a Python script.

## Success Criteria

- All 17 existing participants can log in to the new site with no data loss.
- A new user can sign up and set up a portfolio for next month without any admin involvement, as long as the account limit hasn't been reached.
- Site remains hostable entirely on GitHub Pages (free) + Firebase Spark plan, with all price/symbol data version-controlled in the repo rather than stored in Firebase.
